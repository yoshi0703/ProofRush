# EnvTrack — Environmental & Computational Science Track (Tier C)

海洋ゴミ・海洋循環シミュレーション・数理最適化・統計モデリング等の環境科学課題を扱う専用トラック。

## 完了基準（Lean 4 形式証明の代替となる厳格な科学的検証基準）
1. **実データ再現性**: 公開実データ（漂流ブイ観測・衛星データ・海洋再解析データ等）を取得・前処理・実験する再現可能なスクリプト。
2. **ベースライン定量比較**: 既存手法に対する定量的ベンチマーク結果（誤差指標・計算コスト等）。
3. **感度分析と統計的検定**: ハイパーパラメータ・初期条件への感度分析、および信頼区間・有意差検定（p値・ブートストラップ等）。
4. **任意の数理形式化**: モデルの核となる純粋数理命題が切り出せる場合のみ、`Formal/` 側に Lean 4 証明を併設可。
