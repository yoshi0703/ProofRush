# Manuscript font fallback

ProofRushDirectorJP.otf is a modified, renamed subset of Noto Sans CJK JP Regular from the [upstream Sans2.004 release](https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/OTF/Japanese/NotoSansCJKjp-Regular.otf). It contains only the space and the four glyphs in 大束良明. The subset and its redistribution are covered by the SIL Open Font License 1.1. [Copyright and license](OFL.txt).
