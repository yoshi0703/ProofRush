# The exact prime-difference strata of primitive words

László Kászonyi conjectured that the intermediate classes in his classification of primitive binary words are stratified semilinear. We give a negative answer for every intermediate class and every admissible number of occurrences of the marked letter. The same proof corrects the rank-one clause of Theorem 6 in the original article. [Kászonyi, 2010, printed p. 328](https://publi.math.unideb.hu/paper/1506/download/10_5486_PMD_2010_4680.pdf#page=16) · [English manuscript](paper/paper.pdf)

Write a word with exactly $n$ occurrences of $a$ as a list of the lengths of the following $b$-runs. A class of rank $r$ allows nonzero mixed differences on $r$ prime axes and requires all higher differences to vanish. Every period of a linear set contained in this class must obey the same vanishing equations. On an odd grid the equations exclude every nonzero period supported at one or two positions. On an even grid the only possible exception is a pair of equal increments half a cycle apart. A family of primitive words with growing first differences defeats those periods as well.

The proof also determines which lower-rank classes contain any infinite context-free sublanguage. Such a sublanguage exists exactly when $n$ is even and the rank is one less than the number of distinct prime divisors of $n$. In that case every context-free sublanguage has an exponent set given by a finite union of points and arithmetic progressions, each adding the same amount at antipodal positions. The proof credits the classical language and product-code theorems used in this classification. [Manuscript, Theorems 1 and 4](paper/paper.pdf)

## What the kernel verifies

For $n=105=3\cdot5\cdot7$ and rank 2, the Lean theorem `Kasonyi105.page328_intersection` negates the original stratified-semilinearity assertion for the intersection of the rank class with the exponents of the actual binary primitive-word language. The definition permits arbitrary integer box scales coprime to their prime denominators. The proof also covers the alternative reading in which some pair of axes must be active. It quantifies over unbounded exponents, all proper word powers and arbitrary finite stratifications. A second group of targets proves the product-grid support bound, its attainment and its equality cases for integer arrays. [Exact statement and proof](lean/PublishedConjecture.lean) · [General grid proof](lean/GridSupport.lean)

Lean 4.36.0 and a separately built Rust kernel verified ten targets from seven modules. The Rust checker accepted 6,792 declarations. The export uses the standard foundations `propext`, `Quot.sound` and `Classical.choice`. The paper proves the general cyclic-to-grid transfer and the context-free statements using the bounded-language theorem.
