# Research record

The sessions started on 26 November 2026 UTC. The coordinator compared recent theorems, the graph researcher tried finite counterexamples, the sequence researcher tried general enumerative proofs, and the formalizer set up Lean and an independent kernel. Useful attempts that led to published predecessors are documented here.

|Approach|Evidence and disposition|
|---|---|
|Conjectures involving burning and Slater number|A complete graph attached to a path gave a 15-vertex counterexample. Christopher had already published unbounded burning number at Slater number two, including the relevant graph construction. In the corresponding lollipops the long pendant path also gives unbounded diameter. Both proposals were dropped. [September 2026 primary record](https://doi.org/10.6084/m9.figshare.33476293)|
|Binary matrices with every row and column sum at most two, A401159|Enumeration yielded 1, 7, 49, 265, 1081, 3481, 9367 for zero through six rows with three columns. A dynamic program and inclusion–exclusion agreed with the polynomial through 200 rows, and the all-row Lean theorem succeeded. A prior public proof of the same three-column conjecture was found, and the two-column count was already in OEIS. Dropped as a discovery. [Earlier proof](https://github.com/s66lem/conjectures/tree/main/results/mathar-a401159) · [Zenodo](https://zenodo.org/records/24559959) · [Two columns](https://oeis.org/A086601)|
|Single-loop mirror configurations on two rows, A400778|Tracking boundary arc identifications gave the count 4^(k−1) for k≥1. A second check enumerated 74,898 labeled configurations across the tested sizes. A Lean formalization of the geometric predicate passed an independent checker. GitHub commit search uncovered earlier publications covering the same formula, including a Zenodo record at 01:21:58 UTC on 26 November. Dropped. [Earlier general proof](https://zenodo.org/records/24546586) · [Independent public repository](https://github.com/IvanGrigin/mirror-curves-a400778)|
|Other sequence leads|Earlier resolutions eliminated divisor-block maxima A400194/5, a central-coefficient valuation A402341, diagonal domicule counts A401673, Riordan complements A401496, the square/triangular multiplier problem A400520 and a sparse primality test A400454. [Divisor blocks](https://www.trureturing.org/research/oeis-a400194-two-dense-divisor-block-maximum/) · [Central coefficient](https://github.com/s66lem/conjectures/tree/main/results/hussain-a402341) · [Domicules](https://github.com/derekblair/math-proofs/tree/main/preprints/s017-a401673) · [Riordan](https://github.com/A-guy-with-AI/A401496-proof/commit/f53271688e00c7a2e2dcb0ffe4d25a4df0b229ab) · [Square/triangular](https://github.com/the-omega-institute/trureturing/commit/60248521d80e74eaffbfa06d670082d7cca842e5) · [Primality test](https://math.stackexchange.com/a/5150708)|
|Visible Gaussian integers, A401897|A uniform lattice-point count suggested the asymptotic 48n/π². A 15 November public record had already derived this exact limit from Hensley’s 1994 theorem, so it was dropped on follow-up. The release register originally contained 36 candidates, including this one. [Prior application](https://github.com/the-omega-institute/trureturing/issues/30684) · [Hensley](https://doi.org/10.2140/pjm.1994.166.295)|
|Modular coloring for heptomino tilings|For 13 shapes marked unsolved, a search for multiplicative coloring obstructions over small prime fields through 73 found none. This test rules out only the tested certificates. [Problem collection](https://sicherman.net/nshkt/index.html)|
|Large-diameter regular graphs|Joining short cubic blocks by bridges raised the diameter while retaining a six-part clique cover. The graph is the known G₁₄. Alternative calculations used breadth-first search, a partition and an independent set, and exact dynamic programming. Literature checks shifted the attribution from a possible new graph to a new application of a known graph. [Earlier construction](https://people.cs.uchicago.edu/~laci/students/guiduli.dir/barry-brand-imrich.pdf) · [Priority review](priority.md)|

The competing sequence publications were absent from our initial exact-term code searches. We added commit, repository and archival searches before accepting the graph result. The family of graphs with more central blocks was also investigated as a possible strengthening. The current formal release proves the single counterexample and the negations it entails.
